# **Practical: Bank Customer Churn Prediction Using Artificial Neural Network (ANN)**

## **1. Theory**

**Aim:** To predict whether a bank customer will leave the bank or continue using its services using an Artificial Neural Network (ANN).

**What is Customer Churn?**

Customer churn means when a customer stops using a company's or bank's services.

This is a **binary classification problem** because there are only two possible outputs:

- **0 – No Churn:** Customer stays with the bank.
- **1 – Churn:** Customer leaves the bank.

**What is ANN?**

Artificial Neural Network (ANN) is a machine learning model inspired by the working of the human brain. It consists of connected units called neurons, arranged in layers.

**Layers used in this program:**

1. **Input Layer:** Takes customer information such as age, gender, country, balance and credit score.
2. **Hidden Layers:** Learn patterns from the customer data.
3. **Output Layer:** Predicts whether the customer will leave or stay.

**Important concepts used:**

- **Label Encoding:** Converts text values into numbers.
- **One-Hot Encoding:** Converts categories into separate columns containing 0s and 1s.
- **StandardScaler:** Scales numerical values so they are on a similar range.
- **ReLU:** Activation function used in hidden layers.
- **Sigmoid:** Converts the final output into a probability between 0 and 1.
- **Binary Crossentropy:** Loss function used for binary classification.
- **Adam:** Optimizer used to update model weights and reduce errors.
- **Confusion Matrix:** Shows correct and incorrect predictions.
- **Classification Report:** Displays precision, recall and F1-score.

**Working of the program:**

1. Load the bank customer dataset.
2. Remove unnecessary columns.
3. Separate input features and output.
4. Convert text columns into numerical values.
5. Split the dataset into training and testing data.
6. Scale the input data.
7. Build and train the ANN model.
8. Predict customer churn.
9. Evaluate the model using a confusion matrix, classification report and accuracy.
