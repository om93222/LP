Part 1: Theory
1. What is the aim of this practical?
Aim: To predict the fare amount of an Uber ride based on pickup and drop-off locations using Machine Learning algorithms.
2. What is Uber fare prediction?
Uber fare prediction is a Machine Learning application that predicts the cost of a ride based on different factors, such as:
- Pickup location
- Drop-off location
- Number of passengers
- Pickup time
- Distance between locations
For this practical, we use a dataset containing previous Uber rides to train our Machine Learning model.
3. Which type of Machine Learning is used?
Supervised Machine Learning – Regression

Why?
- Supervised learning means the model is trained using data that already contains the correct answers.
- Regression means predicting a numerical value.
- Here, we predict the fare amount, which is a numerical value.
4. Algorithms used
1. Linear Regression

It predicts the fare by finding a linear relationship between input features and the fare amount.

2. Random Forest Regression

It uses multiple decision trees and combines their predictions to produce the final result.
5. What is RMSE?
RMSE stands for Root Mean Square Error.

It measures the difference between actual fares and predicted fares.
- Lower RMSE = Better prediction.
- Higher RMSE = Less accurate prediction.
