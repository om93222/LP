# **Part 1: Theory**

## **1. Aim**

To implement SMS Spam Detection using Machine Learning algorithms and classify messages as Spam or Ham.

## **2. Introduction**

SMS Spam Detection is a Machine Learning application used to identify unwanted or fraudulent messages.

It classifies SMS messages into two categories:

- **Spam:** Unwanted messages, advertisements, fake offers or suspicious messages.
- **Ham:** Normal and genuine messages.

For example:

| SMS message                                    | Category |
| ---------------------------------------------- | -------- |
| Congratulations! You won a lottery. Claim now! | Spam     |
| Hello, how are you?                            | Ham      |
| Win a free iPhone. Click here!                 | Spam     |
| I will meet you tomorrow.                      | Ham      |

## **3. Type of Machine Learning**

We use **Supervised Machine Learning – Classification**.

Why?

- Supervised learning uses labelled data for training.
- Classification predicts categories or classes.
- Here, the two classes are Spam and Ham.

## **4. Algorithms used**

**1. K-Nearest Neighbors (KNN)**

KNN classifies a message based on the nearest similar data points.

**2. Linear Support Vector Machine (Linear SVM)**

Linear SVM separates Spam and Ham messages using a linear decision boundary.

**3. Polynomial Support Vector Machine (Polynomial SVM)**

Polynomial SVM uses a polynomial decision boundary to classify messages.

## **5. What is CountVectorizer?**

CountVectorizer converts text messages into numerical values based on the frequency of words.

Machine Learning algorithms cannot directly understand normal text, so we convert text into numbers.

For example:

- Message 1: "I love Python"
- Message 2: "I love Java"

Vocabulary: `I, love, Python, Java`

| Message   | I | love | Python | Java |
| --------- | - | ---- | ------ | ---- |
| Message 1 | 1 | 1    | 1      | 0    |
| Message 2 | 1 | 1    | 0      | 1    |

This is called a Bag of Words representation.

## **6. What is Accuracy?**

Accuracy measures how many predictions are correct compared to the total predictions.

\\[ Accuracy = \frac{Correct\ Predictions}{Total\ Predictions}\times100 \\]

Higher accuracy generally indicates better classification performance.
